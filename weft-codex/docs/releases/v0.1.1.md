# weft-codex v0.1.1: Native surface polish

这个版本进一步收紧 Codex 原生体感，并让公开项目首页更接近产品说明，而不是内部
迁移记录。

## 变化

- Sidebar 不再展示 `Desktop compatibility mode` 或“桌面兼容模式”；
- CSP 探测、自动 bypass、退出恢复与诊断日志仍由 Host 在后台处理；
- README 改为与 Weft 一致的产品叙事结构，并新增独立中文版本；
- 用户界面与 README 统一使用 Task 术语。

## 安装

当前二进制支持 macOS arm64，需要官方 Codex 位于
`/Applications/ChatGPT.app`。

```sh
gh release download v0.1.1 \
  --repo SoloJiang/weft-codex \
  --pattern 'weft-codex-0.1.1-macos-arm64.tar.gz*'
shasum -a 256 -c weft-codex-0.1.1-macos-arm64.tar.gz.sha256
tar -xzf weft-codex-0.1.1-macos-arm64.tar.gz
cd weft-codex-0.1.1-macos-arm64
./install.sh
weft-codex doctor
weft-codex
```

默认安装到 `~/.local`，升级会切换版本化 runtime，不会读取或迁移原 Weft 数据。

## Developer Preview 说明

本版本已完成 ad-hoc 签名和本机端到端验证，但尚未使用 Apple Developer ID
签名和 notarization。通过浏览器下载时，macOS Gatekeeper 可能要求用户确认。
