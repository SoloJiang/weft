# weft-codex v0.1.0 — Developer Preview

首个可安装版本，把 Weft 的多仓库、Workspace、Issue/Kanban、Lead/Worker 和
Thread Bus 工作流接入官方 Codex Desktop。Host 不复制、修改或重签 Codex App；
用户看到和操作的仍是官方 Codex。

## 主要能力

- 全局 `weft-codex` CLI，一条命令启动官方 Codex、weftd 并注入 Weft Mode；
- Workspace、Issue、Kanban 和多仓库录入与自动分析；
- Lead 在原生 Codex Thread 中拆解任务并自动调度 Worker；
- Worker 独立 Thread、git worktree、durable Thread Bus 与重启恢复；
- Codex 主题和语言上下文同步；
- `weft-codex --safe-mode` 只启动官方 Codex，不启动 weftd、不注入 UI。

## 安装

当前二进制支持 macOS arm64，需要官方 Codex 位于
`/Applications/ChatGPT.app`。

```sh
gh release download v0.1.0 \
  --repo SoloJiang/weft-codex \
  --pattern 'weft-codex-0.1.0-macos-arm64.tar.gz*'
shasum -a 256 -c weft-codex-0.1.0-macos-arm64.tar.gz.sha256
tar -xzf weft-codex-0.1.0-macos-arm64.tar.gz
cd weft-codex-0.1.0-macos-arm64
./install.sh
weft-codex doctor
weft-codex
```

默认安装到 `~/.local`，数据保存在独立的 `~/.weft-codex`；不会读取或迁移原
Weft 数据。

## Developer Preview 说明

本版本已完成 ad-hoc 签名和本机端到端验证，但尚未使用 Apple Developer ID
签名和 notarization。通过浏览器下载时，macOS Gatekeeper 可能要求用户确认。
请先运行 `weft-codex doctor`；需要无注入回退时使用
`weft-codex --safe-mode`。

验证覆盖 55 个 Codex app-server 测试、46 个 core 测试、25 个 Launcher 测试、
UI typecheck/build、发行包 SHA-256、隔离全局安装、MCP roundtrip 和退出清理。
